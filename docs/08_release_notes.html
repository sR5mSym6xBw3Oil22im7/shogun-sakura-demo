Release Notes

主な実装内容

フロントエンド

高級感のある和風商品ページ、注文導線、履歴画面、フローティングAI案内を実装しました。

バックエンド

注文登録、履歴取得、ヘルスチェック、AIチャットのREST APIを実装しました。

データ

外部PostgreSQLへ依存せず、Render Web Service内のH2インメモリDBへ一本化しました。

AI・MCP

固定許可ページの本文だけを根拠とし、内部トークンで保護されたMCP経由で本文を取得する構成を実装しました。

公開・運用

GitHub PagesとRenderを組み合わせた分離公開、Docker Composeによるローカル再現、環境変数による秘密管理を整備しました。

Important Notes

重要事項

デモ環境：注文は実際の販売・決済を伴いません。確認画面から送信される情報は自動生成した架空データです。
データ保持：注文履歴はバックエンド再起動・再デプロイで初期化されます。恒久保存が必要な運用には利用しないでください。
AI回答範囲：サイトに掲載された内容だけを回答対象とします。一般知識や外部情報への回答は行いません。
