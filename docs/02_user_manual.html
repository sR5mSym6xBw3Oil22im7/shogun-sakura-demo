Getting Started

利用開始

公開環境ではトップページへアクセスすると、商品紹介、注文デモ、注文履歴への導線、画面右下のAI案内が表示されます。PC・タブレット・スマートフォンの一般的なモダンブラウザで利用できます。

公開URL：
フロントエンド：https://sr5msym6xbw3oil22im7.github.io/shogun-sakura-demo/frontend/
バックエンド稼働確認：https://shogun-sakura-demo.onrender.com/api/health
Browse

商品情報を確認する

  1. トップページを開くヒーローエリアに商品コンセプトと商品画像が表示されます。
  2. 「商品セットを見る」を選択する商品の特徴とセット構成へ移動します。
  3. 購入デモ欄を確認する価格は1セット4,800円（税込・デモ価格）です。実販売・決済・在庫引当は行われません。
Order Demo

注文デモを操作する

  1. 入力欄を編集する氏名、メールアドレス、郵便番号、住所、数量、備考を入力します。数量は1～9です。
  2. 「注文確認」を選択するブラウザ側の入力検証に合格すると確認画面へ進みます。
  3. 確認画面を確認する個人情報保護のため、入力値は引き継がれず、確認画面では自動生成した架空データが表示されます。
  4. 「注文」を選択する架空データがバックエンドへ送信され、注文IDが採番されます。
  5. 完了画面を確認する注文受付完了の案内が表示されます。
データ保持：注文はH2インメモリDBに保存されます。バックエンドの再起動または再デプロイ後は履歴が初期化されます。
History

注文履歴を確認する

  1. 上部メニューの「注文履歴一覧表示」を選択する注文履歴ページへ移動します。
  2. 取得完了を待つ注文ID、商品名、氏名、メール、郵便番号、住所、数量、合計金額、備考、登録日時が表示されます。
  3. 表示されない場合バックエンドの起動状態とブラウザのネットワーク接続を確認します。Renderのスリープ解除直後は応答まで時間がかかる場合があります。
AI Guide

AI案内を利用する

  1. 画面右下のAI案内アイコンを選択するチャットパネルが開きます。
  2. 質問を入力する500文字以内で、価格、セット内容、用途などサイト掲載情報について質問します。
  3. 送信するEnterで送信、Shift + Enterで改行できます。
  4. 回答を確認するサイト本文に根拠がある場合のみ回答します。根拠がない場合は回答できない旨が表示されます。

質問例

  • セットの価格はいくらですか？
  • セット内容を教えてください。
  • どのような用途を想定していますか？

対象外の質問

  • サイトに記載のない一般知識
  • 外部サイトの情報
  • 内部設定や秘密情報
Troubleshooting

画面メッセージと対応

状況主な原因対応
フォームの項目が赤く表示される未入力、形式不正、文字数超過表示された内容に沿って修正します。
注文送信に失敗するAPI停止、通信断、CORS設定不一致時間を置いて再実行し、継続時は運用担当へ連絡します。
注文履歴を取得できないバックエンド停止、初回起動待ちヘルスチェックURLで稼働状態を確認します。
AI案内が回答できないサイト本文に根拠がない、Gemini連携障害サイト掲載内容に絞って質問を具体化します。
以前の注文が消えたバックエンド再起動・再デプロイ本リリースの仕様です。必要に応じて再登録します。
