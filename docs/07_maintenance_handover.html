Common Changes

代表的な変更手順

商品価格を変更する

  1. frontend/index.html の表示価格を変更します。
  2. OrderService.java の UNIT_PRICE を同じ金額へ変更します。
  3. チャット回答のフォールバックと受入テストを確認します。

AIの参照ページを追加する

  1. SiteContentService.ALLOWED_PAGE_SUFFIXES へ固定パスを追加します。
  2. 同一スキーム・ホスト・ポート内であることを確認します。
  3. 総文字数上限18,000文字への影響を評価します。
  4. 回答根拠とプロンプトインジェクション耐性を再確認します。

フロントエンドのドメインを変更する

  1. 各HTMLの window.API_BASE_URL を確認します。
  2. render.yaml とRenderの ALLOWED_ORIGINS を更新します。
  3. 公開URLを参照する SITE_SOURCE_BASE_URL を更新します。
  4. CORSとAI本文取得を再確認します。

Production Readiness

本番化ロードマップ

優先度A：セキュリティとデータ

認証・認可、PostgreSQL等の永続DB、暗号化、秘密管理、個人情報の保存方針、管理者画面を実装します。

優先度B：信頼性

CI/CD、バックアップ、監視・通知、レート制限、タイムアウト・リトライ、構造化ログを追加します。

優先度C：機能拡張

商品マスタ、在庫、決済、会員、検索、AI会話履歴、複数ページの自動インデックス化を追加します。

優先度D：品質と運用

アクセシビリティ監査、ブラウザ互換試験、負荷試験、脆弱性診断、運用SLAを整備します。

Handover Checklist

引継ぎチェックリスト

  • GitHubリポジトリへの管理権限を引き継ぐ
  • Renderサービスへの管理権限を引き継ぐ

  • 本番化する場合の追加要件と予算・日程を別途定義する
