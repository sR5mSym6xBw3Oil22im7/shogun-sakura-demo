Purpose

目的と適用範囲

本システムは、Webサイト内の掲載情報を根拠として回答するAI案内機能と、REST APIを利用したデータ登録・一覧表示の基本構成を検証するためのデモ実装です。サンプルサイト「SHOGUN SAKURA」を通じて、静的サイトとクラウド上のJava APIを分離した構成を確認できます。

カード型の学習コンテンツポータルなど、多数のページやカテゴリを持つWebサイトへのAI案内導入を検討する際にも、許可ページの本文取得、回答根拠の限定、内部トークン認証という設計パターンを展開できます。

適用範囲：本リリースは検証・ポートフォリオ用途です。実決済、在庫管理、会員認証、永続的な注文管理は含みません。
Functions

提供機能

商品紹介

商品画像、特徴、セット内容、デモ価格を静的ページで表示します。

注文デモ

入力検証後、確認画面で生成した架空データを注文APIへ送信します。

注文履歴

H2メモリDBに保存された注文を一覧表示します。

AI案内

許可されたサイト本文のみを根拠にGeminiが短い日本語回答を返します。

ヘルスチェック

Renderの稼働監視に利用できる軽量な状態確認APIを提供します。

内部MCP

サイト本文取得ツールを内部トークン付きのMCPエンドポイントとして提供します。

Security

セキュリティ設計

  • 公開REST APIは設定済みオリジンからのGET / POST / OPTIONSに限定
  • 内部MCPは専用ヘッダー X-MCP-Internal-Token で認証
  • サイト本文の取得先は固定の許可ページに限定し、別ホスト・別ポート・リダイレクトを拒否
  • AI回答の根拠を取得済みサイト本文だけに制限
  • APIキー、内部トークン等を含む回答を検出した場合は採用しない
  • 注文・チャットの入力長と形式をサーバー側で検証
本番化時の必須追加：注文履歴APIの認証・認可、永続DB、アクセスログ管理、レート制限、個人情報取扱方針、バックアップ、脆弱性診断を追加してください。
