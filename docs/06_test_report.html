JUnit実行について：テスト資産はソースに実装済みです。本ドキュメント作成環境ではMaven依存関係の外部取得が制限されていたため、JUnit一括実行は対象外としました。ネットワーク接続可能なJava 21環境またはDocker環境で、以下の手順により実行できます。
cd backend
./mvnw test

# Docker Compose連携テストを含める場合
docker compose up --build -d
export CHROME_BIN="$(command -v google-chrome || command -v chromium)"
cd backend
./mvnw test

Quality Notes

品質上の所見

  • フロントエンドは外部フレームワークに依存せず、構成が明快です。
  • サーバー側バリデーションが実装され、ブラウザ側のみへ依存していません。
  • AI回答はサイト本文限定、秘密情報抑止、取得先許可リストにより安全側へ設計されています。
