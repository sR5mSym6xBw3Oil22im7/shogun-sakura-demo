POST /api/orders

注文登録

注文デモの架空データをH2メモリDBへ保存します。単価は4,800円で固定され、合計金額は数量からサーバー側で算出します。

リクエスト

{
  "name": "テスト太郎",
  "email": "test@example.com",
  "postalCode": "100-0001",
  "address": "東京都千代田区1-1",
  "quantity": 2,
  "note": "demo order"
}
項目必須制約
name必須空白不可、50文字以内
email必須メール形式、100文字以内
postalCode任意数字とハイフン、8文字以内
address必須空白不可、200文字以内
quantity必須1～9の整数
note任意200文字以内

成功レスポンス：201 Created

{
  "orderId": 1,
  "message": "注文を受け付けました。",
  "createdAt": "2026-07-26T12:00:00+09:00"
}
GET /api/orders

注文履歴取得

現在のバックエンドプロセス内に保存されている注文を、注文IDの昇順で返します。

[
  {
    "orderId": 1,
    "productName": "SHOGUN SAKURA SET",
    "customerName": "テスト太郎",
    "email": "test@example.com",
    "postalCode": "100-0001",
    "address": "東京都千代田区1-1",
    "quantity": 2,
    "totalAmount": 9600,
    "note": "demo order",
    "createdAt": "2026-07-26T12:00:00+09:00"
  }
]
デモ仕様：認証なしで一覧取得できます。本番環境へ転用する場合は管理者認証とアクセス制御が必須です。
POST /api/chat

AIチャット

質問を受け取り、許可ページ本文を根拠とする短い日本語回答を返します。会話履歴はDBへ保存しません。

リクエスト

{ "message": "セットの価格はいくらですか？" }

message は必須、空白不可、500文字以内です。

成功レスポンス：200 OK

{ "answer": "桜の押し花と将軍の扇セットは、税込のデモ価格で4,800円です。" }

根拠がない場合

{ "answer": "このサイト内に記載がないため、お答えできません。" }
POST /mcp

内部MCP

サイト本文取得ツール get_site_content を提供する内部エンドポイントです。フロントエンドから直接呼び出しません。

項目仕様
認証ヘッダーX-MCP-Internal-Token
GET405 Method Not Allowed
トークン不正401 Unauthorized
許可外Origin403 Forbidden
ツール名get_site_content

取得対象はトップ、注文履歴、注文確認、注文完了の固定許可ページです。1ページ最大5,000文字、合計最大18,000文字、キャッシュは5分です。

HTTP Status

ステータスコード

コード意味主なケース
200成功取得、AI回答
201作成成功注文登録
400不正リクエスト入力検証エラー、JSON不正
401認証失敗内部MCPトークン不正
403許可拒否内部MCPのOrigin不正
405Method不許可MCPへのGET
500サーバーエラー予期しない内部例外
