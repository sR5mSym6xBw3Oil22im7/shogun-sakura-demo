Local Setup

Docker Composeでローカル起動

  1. 環境設定ファイルを作成する
    cp .env.example .env
  2. 必須値を設定する
    GEMINI_API_KEY=設定値
MCP_INTERNAL_TOKEN=十分に長いランダム値
MCP_BASE_URL=http://localhost:8080
  3. サービスを起動する
    docker compose up --build
  4. ブラウザで確認する

    フロントエンド：http://localhost:5500/frontend/
    バックエンド：http://localhost:8080/api/health

  5. 停止する
    docker compose down

GitHub Pages

フロントエンド公開

  1. 対象ブランチへ変更を反映する静的ファイルが frontend/ 配下にあることを確認します。
  2. GitHub Pagesの公開元を設定するリポジトリ設定で対象ブランチとルートを指定します。
  3. .nojekyll を維持する静的ファイルをそのまま配信するため、リポジトリルートのファイルを削除しないでください。
  4. 公開URLを確認するhttps://sr5msym6xbw3oil22im7.github.io/shogun-sakura-demo/frontend/

Verification

デプロイ後確認

  1. ヘルスチェック/api/health が200を返すこと。
  2. トップページ画像、CSS、JavaScriptが欠落なく表示されること。
  3. 注文登録注文完了画面へ遷移し、履歴に1件追加されること。
  4. AI案内価格に関する質問へ4,800円と回答できること。
  5. CORSGitHub PagesからAPI呼び出しが成功し、許可外オリジンが拒否されること。
