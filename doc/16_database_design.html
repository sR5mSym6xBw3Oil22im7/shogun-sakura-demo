1. データベース概要

項目内容
DBMSH2 Database（インメモリ）
JDBC URLjdbc:h2:mem:shogun_sakura;DB_CLOSE_DELAY=-1;DB_CLOSE_ON_EXIT=FALSE;DATABASE_TO_UPPER=false
ユーザーsa
スキーマ初期化Spring SQL initでschema.sqlを常時実行
保持期間同一アプリケーションプロセスの稼働中
用途架空のデモ注文のみ

2. ordersテーブル

カラム型NULL制約／初期値説明
idBIGINT不可IDENTITY / PK注文ID
product_codeVARCHAR(50)不可SAKURA_SHOGUN_SET
product_nameVARCHAR(100)不可SHOGUN SAKURA SET
customer_nameVARCHAR(50)不可架空氏名
emailVARCHAR(100)不可架空メール
postal_codeVARCHAR(10)可架空郵便番号
addressVARCHAR(200)不可架空住所
quantityINTEGER不可CHECK 1～9数量
unit_priceINTEGER不可4,800円
total_amountINTEGER不可unit_price×quantity
noteVARCHAR(200)可架空備考
demo_orderBOOLEAN不可DEFAULT TRUEデモ注文識別
created_atTIMESTAMP WITH TIME ZONE不可DEFAULT CURRENT_TIMESTAMP登録日時

3. CRUD

処理SQL概要並び順
注文登録INSERT INTO orders (...) VALUES (...)なし
生成日時取得SELECT created_at FROM orders WHERE id = ?単一行
履歴取得SELECT ... FROM ordersid ASC

4. データ設計上の注意

  • 氏名・メール等は確認画面で生成した架空データだけを保存する。
  • DB制約に加えてAPI Validationで不正値を拒否する。
  • 外部キーを持つ別テーブルは作成しない。
  • 永続化・バックアップ・復元は対象外とする。
