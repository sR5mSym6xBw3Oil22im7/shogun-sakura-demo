システム構成図

利用者ブラウザHTML/CSS/JavaScript
HTTPS
GitHub Pages静的フロントエンド
↘ REST / JSON（CORS）
Render Web ServiceJava 21 / Spring Boot API
H2 In-Memoryデモ注文
内部MCP許可ページ本文取得
Gemini APIサイト限定回答

構成要素

要素役割通信
ブラウザ画面表示、入力検証、注文・履歴・チャット操作GitHub Pagesから取得、RenderへHTTPS API通信
GitHub Pagesfrontend配下の静的ファイルを配信HTTPS
Render Web ServiceREST API、入力検証、注文処理、AI連携HTTPS、内部HTTP、外部HTTPS
H2注文デモデータをプロセス内保存JDBC
MCPサーバー／クライアント許可されたサイト本文をツール形式で取得/mcp、内部トークン
公開サイト本文AI回答の根拠データHTTP GET、リダイレクト禁止
Gemini API本文と質問から日本語回答を生成Google Generative Language API

API経路

経路内容
ブラウザ → Render /api/orders注文登録・履歴取得
ブラウザ → Render /api/chatAI質問・回答
Render → Render /mcp内部サイト本文取得ツール
Render → GitHub Pages許可ページのHTML取得
Render → Gemini APIサイト本文を含む生成リクエスト
