2. 数量操作チェック

  • 変更手段はnumber入力の矢印ボタンまたは上下矢印キーとする。
  • 数字キー、貼付け、ドロップ、マウスホイールによる直接変更を抑止する。
  • 抑止時は「数量は直接入力できません。矢印ボタンか上下の矢印キーで変更してください。」を表示する。
  • 最後に有効だった値を保持し、不正操作後に復元する。

3. チャット入力チェック

条件処理
trim後空文字APIを呼ばず「質問を入力してください。」を表示。
500文字超HTML maxlengthとAPI @Sizeで拒否。
送信中の再送isSendingで抑止し、送信ボタンを無効化。

4. エラー表示方式

  • 項目エラーは各入力欄直下へ表示する。
  • 不正項目にaria-invalid=trueを設定する。
  • 最初の不正項目へフォーカスする。
  • APIのfieldErrorsがある場合は各メッセージを結合して確認画面へ表示する。
