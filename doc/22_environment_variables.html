環境変数一覧

変数名必須既定値設定先用途・注意
PORTRenderで自動8080実行環境Spring Boot待受ポート。
GEMINI_API_KEY必須なしローカル.env / Render SecretGemini API認証。空の場合は起動時に設定エラー。
GEMINI_API_BASE_URL任意https://generativelanguage.googleapis.com/v1beta必要時のみGemini互換テスト先の切替。
MCP_INTERNAL_TOKEN必須なしローカル.env / Render Secret/mcp内部認証。十分長いランダム値を使用。
MCP_BASE_URL必須なしローカル.env / Render SecretMCP接続先のベースURL。
SITE_SOURCE_BASE_URL任意https://sr5msym6xbw3oil22im7.github.io/shogun-sakura-demo/frontend/Compose / 必要時AI根拠本文の取得元。
ALLOWED_ORIGINS任意localhost、GitHub Pages等の組込み値Compose / Renderカンマ区切りのCORS許可Origin。

ローカル設定例

GEMINI_API_KEY=your-gemini-api-key
MCP_INTERNAL_TOKEN=replace-with-a-long-random-token
MCP_BASE_URL=http://backend:8080
# 必要に応じて
# SITE_SOURCE_BASE_URL=http://frontend/frontend/
# ALLOWED_ORIGINS=http://localhost:5500,http://127.0.0.1:5500,null
