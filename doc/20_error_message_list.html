4. ログ方針

  • AI・サイト本文取得の失敗は標準エラーへ概要とスタックトレースを出力する。
  • APIキー、内部トークン、実値の秘密情報はログへ出力しない。
  • 利用者向けには内部構造を出さず、再試行可能な一般メッセージを表示する。
