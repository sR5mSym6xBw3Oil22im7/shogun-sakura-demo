SHOGUN SAKURA

桜の押し花と将軍の扇を紹介する、職業訓練校の卒業制作ポートフォリオ用デモECサイトです。静的フロントエンドとSpring Boot REST APIで、デモ注文、注文履歴、サイト限定AI案内を提供します。

公開URL

  • フロントエンド：https://sr5msym6xbw3oil22im7.github.io/shogun-sakura-demo/frontend/
  • バックエンド：https://shogun-sakura-demo.onrender.com
  • ヘルスチェック：https://shogun-sakura-demo.onrender.com/api/health

主な機能

  • 商品紹介と税込デモ価格4,800円の表示
  • 入力検証付き注文フォーム
  • 利用者の個人情報を送信しない架空注文
  • 注文履歴一覧
  • サイト本文に限定したAI案内
  • ヘルスチェック
  • Docker Composeによる統合起動

必要環境

  • Java 21
  • Docker Engine / Docker Compose v2
  • Bash
  • ChromeまたはChromium（E2Eテスト時）

Docker Compose起動

cp .env.example .env
# .envへGEMINI_API_KEY、MCP_INTERNAL_TOKEN、MCP_BASE_URLを設定
docker compose up --build

フロント：http://localhost:5500/frontend/、バックエンド：http://localhost:8080

手動起動

cd backend
./mvnw clean test
./mvnw spring-boot:run

# 別ターミナルでリポジトリルート
jwebserver -p 5500

主要API

MethodPath概要
GET/api/health稼働状態
POST/api/orders架空注文登録
GET/api/orders注文履歴
POST/api/chatAI案内

注意事項

  • 実販売、決済、在庫管理は行いません。
  • 注文履歴はH2インメモリDBに保存され、再起動で消えます。
  • GEMINI_API_KEY等の秘密値をコミットしないでください。
  • AIはサイトに記載された情報以外へ回答しません。
