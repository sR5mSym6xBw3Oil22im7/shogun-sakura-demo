4. POST /api/chat

リクエスト

{"message":"セットの価格はいくらですか？"}

成功レスポンス：200 OK

{"answer":"税込のデモ価格で4,800円です。"}

サイト本文に根拠がない場合のサーバー応答は「このサイト内に記載がないため、お答えできません。」とする。フロントエンドではこの文言を「応答なし」として表示する。

5. エラーレスポンス

{
  "message": "Invalid request.",
  "fieldErrors": {
    "email": "正しいメールアドレス形式で入力してください。"
  }
}
HTTP条件
400 Bad RequestBean Validation違反、JSON読取不能、型不一致。
401 UnauthorizedMCP内部トークンなし・不一致。
403 ForbiddenMCPへ許可外Originからアクセス。
405 Method Not AllowedMCPへGETアクセス。
500 Internal Server Error予期しないサーバー例外。
