1. プロジェクト概要

項目内容
プロジェクト名SHOGUN SAKURA
開発区分職業訓練校の卒業制作ポートフォリオ
システム種別静的フロントエンド＋REST APIによるデモECサイト
公開先https://sr5msym6xbw3oil22im7.github.io/shogun-sakura-demo/frontend/
開発期間2026年6月15日～2026年7月23日
リリース版1.0.0
開発ステータスリリース済み

2. 開発目的

  • HTML/CSS/JavaScriptによる画面実装と、Java/Spring BootによるAPI実装を一つの作品として示す。
  • 商品紹介、注文デモ、注文履歴、AI案内を通してフロントエンドとバックエンドの連携を示す。
  • 外部AI API、MCP、Docker、クラウド公開を組み合わせ、実務に近い開発工程を経験する。

3. 対象ユーザー

ユーザー利用目的
ポートフォリオ閲覧者画面デザイン、操作性、技術構成、実装範囲を確認する。
採用担当者・講師要件定義からリリースまでの成果と、フロント・バック双方の実装力を確認する。
開発者ローカル環境で起動し、API・データ保存・AIチャットを確認する。

4. 成果物

  • 公開フロントエンド一式
  • Spring Boot REST API
  • H2データベース定義
  • AIチャット連携機能
  • Docker / Docker Compose構成
  • Renderデプロイ定義
  • 単体・結合・E2Eテストコード
  • 開発・設計・テスト・リリース文書

5. 開発工程

要件定義目的・機能・対象範囲を確定
設計画面・API・DB・外部連携・セキュリティを設計
実装（コーディング）フロントエンド、バックエンド、AI連携を実装
テスト単体、結合、E2E、リリース確認を実施
リリースGitHub PagesとRenderへ公開

6. 開発範囲

商品セットの紹介、デモ注文、注文履歴、サイト本文に限定したAI案内を対象とする。実売、決済、認証、在庫連携は対象外とする。
